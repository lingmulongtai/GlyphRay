Built to avoid the software-encoder trap

Hardware acceleration is verified before live streaming starts instead of silently degrading into CPU encoding

VideoToolbox as a product gate

The Mac host requests a VideoToolbox hardware encoder before live streaming, surfaces whether the active session is hardware accelerated, and defaults to a high-bitrate low-latency H.264 profile.

Default preview
H.264 · 1920×1080@60 · 45 Mbps

Fallback behavior

    Hardware encode first

    Realtime packets

    Keep video datagrams bounded with backpressure counters instead of letting stale frames accumulate latency.
